S. M PRO TEAM VersionStatus

English

S. M PRO TEAM VersionStatus is a Godot Engine plugin for checking the game version and detecting the availability of a new update.

The plugin connects to the official S. M PRO TEAM version management server, retrieves the version information associated with your Project ID, compares the local game version with the version available on the server, and provides the update information for use inside your game.

Requirements

• Godot 4.5 or later.
• An active internet connection.
• A Project ID issued by the S. M PRO TEAM dashboard.

Installation

1. Install the plugin inside your Godot project.
2. Open your project in Godot.
3. Go to Project > Project Settings > Plugins.
4. Enable S. M PRO TEAM VersionStatus.

Getting a Project ID

1. Open the official S. M PRO TEAM dashboard.
https://s-m-pro.onrender.com/dashboard

2. Sign in with your Google account.

3. Create a new project.

4. Enter the required project information:
• Game or application name.
• Current version number.
• Update status, optional or mandatory.
• Update link.

5. Create the project and copy the generated Project ID.

The Project ID looks like this:

"SMP-XXXXXXXX"

Plugin Setup

After enabling the plugin, add the Version Status node to your project.

1. Open your main scene.
2. Click Create New Node.
3. Search for Version Status.
4. Add the Version Status node to the main scene.

The Version Status node should be added to the main scene so that the plugin can perform its version check when the game starts.

Setting the Game Version

Select the Version Status node.

In the Inspector, find the Your_game_version property.

Enter the current version of your game.

Example:

"1.0.0"

The local game version will be compared with the version associated with your Project ID on the S. M PRO TEAM server.

Setting the Project ID

Select the Version Status node.

In the Inspector, find the project_id property.

Enter the Project ID that you received from the S. M PRO TEAM dashboard.

Example:

"SMP-XXXXXXXX"

Replace the example with your actual Project ID.

After setting Your_game_version and project_id, the basic setup is complete.

Creating a Custom Update Pop-up

VersionStatus allows you to create and customize your own update Pop-up inside your game.

You can use Godot UI nodes such as:

• ColorRect.
• Panel.
• Sprite2D.
• Label.
• Button.
• Other Control nodes.

The Pop-up nodes must be children of the Version Status node.

You can design the Pop-up according to the style of your game without changing the main VersionStatus system.

Update Button

After creating your update button, select the Version Status node.

In the Inspector, assign your update button to the update_button property.

When an update is available, this button can be used to open the update link provided by the S. M PRO TEAM server.

Later / Skip Button

If your update allows the player to skip or postpone the update, create a Later / Skip button.

Select the Version Status node and assign the button to the skip property in the Inspector.

For mandatory updates, the Later / Skip option is not available when the update requires the player to update the game.

Version Checking

When the game starts, VersionStatus connects to the official S. M PRO TEAM version management server.

The plugin retrieves the version information associated with the configured Project ID.

It then compares the local game version with the server version.

If a newer version is available, the plugin provides the update information to your game.

The update link configured for the project is also made available for opening the update page.

Update Types

VersionStatus supports optional and mandatory updates.

Optional Update

The player can update the game or continue playing, depending on how your Pop-up is configured.

Mandatory Update

The player must update the game before continuing.

The Later / Skip option is not available for a mandatory update.

Project Management

Game version information is managed through the S. M PRO TEAM dashboard.

You do not need to create or upload your own version management server.

Your Godot project only needs the Project ID generated by the S. M PRO TEAM dashboard.

Guidance:

When the game starts, the plugin automatically sets the Visible property of the Version Status node to false. This hides the Version Status node and all of its child UI nodes, including the Pop-up nodes that you created and customized.

The plugin then checks the game version and determines whether a new update is available.

When a new update is detected, the plugin automatically changes the Visible property of the Version Status node to true. This makes the Version Status node and all of its child nodes visible, including the Pop-up interface that you designed.

Therefore, you should place all the Pop-up UI nodes that you want to display when an update is available as children of the Version Status node.

You do not need to change the Visible property manually. The plugin automatically controls the visibility of the Pop-up according to the update status.

Note:

Do not modify the Name and Code values under the Version tab in the Export window, whether you are exporting for Android or any other platform.

The plugin automatically manages these values based on the version number entered in the Your_game_version property of the Version Status node in the Inspector.

Manually modifying the Name and Code values under the Version tab in the Export window may prevent the plugin from working correctly and may also cause installation issues after exporting the game.

العربية

S. M PRO TEAM VersionStatus

إضافة S. M PRO TEAM VersionStatus لمحرك Godot لفحص إصدار اللعبة ومعرفة توفر تحديث جديد.

تتصل الإضافة بسيرفر S. M PRO TEAM الرسمي لإدارة الإصدارات، وتحصل على معلومات الإصدار المرتبطة بمعرّف المشروع Project ID، ثم تقارن إصدار اللعبة المحلي بالإصدار الموجود في السيرفر، وتوفر معلومات التحديث لاستخدامها داخل اللعبة.

المتطلبات

• Godot 4.5 أو أحدث.
• اتصال نشط بالإنترنت.
• معرّف مشروع Project ID صادر من لوحة تحكم S. M PRO TEAM.

التثبيت

1. قم بتثبيت الإضافة داخل مشروع Godot الخاص بك.
2. افتح المشروع في Godot.
3. انتقل إلى Project > Project Settings > Plugins.
4. فعّل إضافة S. M PRO TEAM VersionStatus.

الحصول على Project ID

1. افتح لوحة تحكم S. M PRO TEAM الرسمية.

https://s-m-pro.onrender.com/dashboard

2. سجّل الدخول باستخدام حساب Google الخاص بك.

3. أنشئ مشروعًا جديدًا.

4. أدخل معلومات المشروع المطلوبة:
• اسم اللعبة أو التطبيق.
• رقم الإصدار الحالي.
• حالة التحديث، اختياري أو إجباري.
• رابط التحديث.

5. أنشئ المشروع وانسخ معرّف المشروع Project ID الذي تم إنشاؤه.

يكون Project ID بهذا الشكل:

"SMP-XXXXXXXX"

إعداد الإضافة

بعد تفعيل الإضافة، قم بإضافة نود Version Status إلى مشروعك.

1. افتح المشهد الرئيسي للعبة.
2. اضغط على Create New Node.
3. ابحث عن Version Status.
4. أضف نود Version Status إلى المشهد الرئيسي.

يجب إضافة نود Version Status إلى المشهد الرئيسي حتى تتمكن الإضافة من إجراء فحص الإصدار عند تشغيل اللعبة.

تحديد إصدار اللعبة

حدد نود Version Status.

من Inspector، ابحث عن الخاصية Your_game_version.

اكتب رقم الإصدار الحالي للعبة.

مثال:

"1.0.0"

ستتم مقارنة إصدار اللعبة المحلي بالإصدار المرتبط بمعرّف مشروعك Project ID على سيرفر S. M PRO TEAM.

تحديد Project ID

حدد نود Version Status.

من Inspector، ابحث عن الخاصية project_id.

أدخل Project ID الذي حصلت عليه من لوحة تحكم S. M PRO TEAM.

مثال:

"SMP-XXXXXXXX"

استبدل المثال بمعرّف مشروعك الفعلي.

بعد تحديد Your_game_version و project_id، يكون الإعداد الأساسي للإضافة قد اكتمل.

إنشاء نافذة التحديث Pop-up مخصصة

تتيح لك VersionStatus إنشاء وتخصيص نافذة التحديث Pop-up الخاصة بك داخل اللعبة.

يمكنك استخدام نودات واجهة Godot مثل:

• ColorRect.
• Panel.
• Sprite2D.
• Label.
• Button.
• نودات Control أخرى.

يجب أن تكون نودات نافذة التحديث Pop-up أبناء لنود Version Status.

يمكنك تصميم النافذة بالشكل الذي يناسب لعبتك دون الحاجة إلى تغيير نظام VersionStatus الأساسي.

زر التحديث

بعد إنشاء زر التحديث، حدد نود Version Status.

من Inspector، قم بإضافة زر التحديث إلى الخاصية update_button.

عند توفر تحديث جديد، يمكن استخدام هذا الزر لفتح رابط التحديث الذي تم تحديده في سيرفر S. M PRO TEAM.

زر لاحقًا أو تخطي

إذا كان التحديث يسمح للاعب بتخطي التحديث أو تأجيله، قم بإنشاء زر Later / Skip.

حدد نود Version Status ثم أضف الزر إلى الخاصية skip من Inspector.

في حالة التحديث الإجباري، لن يكون خيار Later / Skip متاحًا عندما يتطلب التحديث من اللاعب تحديث اللعبة.

فحص الإصدار

عند تشغيل اللعبة، تتصل VersionStatus بسيرفر S. M PRO TEAM الرسمي لإدارة الإصدارات.

تحصل الإضافة على معلومات الإصدار المرتبطة بـ Project ID المحدد.

بعد ذلك، تقارن الإضافة إصدار اللعبة المحلي بالإصدار الموجود على السيرفر.

إذا كان هناك إصدار أحدث متاح، توفر الإضافة معلومات التحديث للعبة.

كما يصبح رابط التحديث المحدد للمشروع متاحًا لفتحه.

أنواع التحديثات

تدعم VersionStatus التحديثات الاختيارية والإجبارية.

التحديث الاختياري

يمكن للاعب تحديث اللعبة أو الاستمرار في اللعب، حسب إعداد نافذة التحديث Pop-up الخاصة بك.

التحديث الإجباري

يجب على اللاعب تحديث اللعبة قبل الاستمرار.

لا يكون خيار Later / Skip متاحًا في حالة التحديث الإجباري.

إدارة المشروع

تتم إدارة معلومات إصدار اللعبة من خلال لوحة تحكم S. M PRO TEAM.

لا تحتاج إلى إنشاء أو رفع سيرفر خاص بك لإدارة الإصدارات.

يحتاج مشروع Godot الخاص بك فقط إلى Project ID الذي يتم إنشاؤه من خلال لوحة تحكم S. M PRO TEAM.

توجيه:

عند تشغيل اللعبة، تقوم الإضافة تلقائيًا بجعل قيمة Visible في نود Version Status تساوي false، مما يؤدي إلى إخفاء نود Version Status وجميع نودات واجهة المستخدم الموجودة بداخلها، بما في ذلك نودات نافذة الـ Pop-up التي قمت بإنشائها وتخصيصها.

بعد ذلك، تقوم الإضافة بفحص إصدار اللعبة والتحقق من وجود تحديث جديد.

عند اكتشاف تحديث جديد، تقوم الإضافة تلقائيًا بتغيير قيمة Visible في نود Version Status إلى true، وبذلك تظهر نود Version Status وجميع النودات التابعة لها، بما في ذلك واجهة الـ Pop-up التي قمت بتصميمها.

لذلك، يجب عليك وضع جميع نودات واجهة الـ Pop-up التي تريد إظهارها عند توفر تحديث كأبناء لنود Version Status.

لا تحتاج إلى تغيير قيمة Visible يدويًا، فالإضافة تتولى إخفاء وإظهار نافذة الـ Pop-up تلقائيًا حسب حالة التحديث.

ملاحظة:

يُمنع تعديل قيمتي Name و Code داخل تبويب Version في نافذة التصدير، سواء كان التصدير لنظام Android أو لأي منصة أخرى.

تتولى الإضافة ضبط هذه القيم تلقائيًا بناءً على رقم الإصدار الذي أدخلته في خاصية Your_game_version من Inspector لنود Version Status.

قد يؤدي إجراء أي تعديل يدوي على قيم Name و Code داخل تبويب Version في نافذة التصدير إلى عدم عمل الإضافة بشكل صحيح، وقد يتسبب أيضًا في حدوث مشاكل في تثبيت اللعبة بعد التصدير.
